Grup kustom — ketik kode dipisah koma, satu baris = satu grup dengan nama di depan titik dua. Contoh: Bakrie: BUMI, BRMS, ENRG, DEWA
Alat OBSERVASI arah aliran — bukan sinyal beli/jual. % Return berbobot = rata-rata perubahan harga grup, dibobot nilai transaksi (saham ramai lebih menentukan). Net Asing = jumlah rupiah beli-jual asing grup hari terakhir. Dua metrik disediakan untuk saling cek — jangan percaya satu angka buta.
